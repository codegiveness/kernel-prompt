# Reformulations

Disclosed reference for [`kernel`](SKILL.md). When a content clause fails the two-reader test, apply one of the seven patterns below. The table shows concrete examples of each pattern in action.

## Patterns

- **Assign a role** — name who is speaking or acting ("Act as a [specific role]")
- **Name the lens** — specify the analytical frame ("Analyze through psychology, strategy, positioning")
- **Set a concrete count** — replace "some" or "a few" with a number ("3 sentences", "5 ideas")
- **Specify the audience** — name who the output is for ("for someone who already knows the basics")
- **Name the operation** — replace a vague verb, modifier, or noun with the specific action ("Break this down", "Challenge this idea")
- **Anchor to a real objection** — ground persuasion in a specific counterargument ("using this real objection: [X]")
- **Add a structural constraint** — require a hook, format, or preservation rule ("with a hook in line 1")

## Examples

Each row shows a vague clause and its specific replacement. Rows marked † are marketing-specific examples that illustrate the pattern, not universal reformulations.

| Vague | Specific | Pattern |
|---|---|---|
| Explain it to me | Act as a [specific role] | Assign a role |
| Give me information about… | Analyze this through psychology, strategy, and positioning | Name the lens |
| What is it? | Analyze this through non-obvious angles — cost, risk, timing | Name the lens |
| Make me a summary | Summarize this through the lens of trade-offs and alternatives | Name the lens |
| Content ideas | Write it for someone who already knows the basics | Specify the audience |
| Strategies for… | Break this concept down | Name the operation |
| Tips for… | Challenge this idea | Name the operation |
| Examples | Give me 3 examples with the pattern explained | Set a concrete count |
| Benefits of… | Analyze the benefits through the lens of trade-offs and alternatives | Name the lens |
| Make me more professional † | Make sure my client understands it in 5 seconds | Add a structural constraint |
| Improve it | Score this against 3 named criteria: [your criteria] | Set a concrete count |
| Make it shorter | Summarize it in 3 sentences without losing the main point | Set a concrete count |
| Make it sound natural | Write it the way I speak, without jargon | Name the operation |
| Write a post about… † | Write a post for [client] with a hook in line 1 | Specify the audience |
| I need content ideas † | Give me 5 Reel ideas with the hook and format | Set a concrete count |
| Fix this | Fix spelling and rhythm without changing my style | Name the operation |
| Make it more persuasive | Rewrite this to overcome this real objection: [X] | Anchor to a real objection |
| Write me a caption † | Give me 3 versions and tell me which one you recommend | Set a concrete count |
